# Evaluation design
No verified labels: precision/recall and fault accuracy are invalid. Compare no-change baseline, causal rolling standardized shift detector and two-sided CUSUM. Same daily aggregated scope, train-only normalization, official chronological split. Daily bins crossing the source boundary must be excluded. Keep scaling artifacts separate from operating changes. Hyperparameters are fixed before test; no test-informed tuning. Report counts, rate, sensitivity/stability, wall time and sampled RSS. Offline segmentation would require explicit retrospective labeling; chosen methods remain causal.
