## Вопросы преподавателя
1. **Почему Python?** Задание требует Python; один Streamlit-процесс покрывает аналитику, UI и SQLite без отдельного сервера.
2. **Что такое long→wide?** Одна строка исходника описывает параметр; pivot превращает параметры в колонки по паре well/timestamp, сохраняя значение и скважину.
3. **Как обрабатываете дубликаты?** Непрозрачное усреднение запрещено; повторный ключ отклоняется при pivot, источник проверен на ноль коллизий.
4. **Почему SQLite?** Локальная установка, нормализация, JOIN/CTE/window functions и простой перенос; реальная версия SQLite записана в manifest.
5. **Как работает LAG?** Получает предыдущее время внутри well+parameter; разность больше часа показывает отсутствующие часовые слоты, а не NULL sensor values.
6. **Почему NULL=0, а пропуски есть?** Источник исключает часы без наблюдений; отсутствующих строк много, хотя имеющиеся hourly values не пусты.
7. **Что означают flags?** Условие на сырых записях переносится на час; это контекст качества, не метка неисправности.
8. **Что такое rolling shift?** Стандартизованное отклонение текущей дневной медианы от средних трех предыдущих допустимых последовательных дней.
9. **Что делает CUSUM?** Накапливает положительные и отрицательные стандартизованные отклонения от обучающего reference с drift и порогом; может повторять уведомления.
10. **Зачем baseline без событий?** Он задает контроль отсутствия детекции; его нулевой счетчик не доказывает хорошую модель.
11. **Почему нет F1?** Нет независимых истинных событий. Вычислить F1 по карточке или собственным уведомлениям означало бы создать недостоверные labels.
12. **Где предотвращена утечка?** Официальный cutoff; train-only median/MAD; causal rolling history; crossing bin исключен; future perturbation test проверяет неизменность ранних outputs.
13. **Когда доступен дневной сигнал?** После конца дня; timestamp маркирует начало бина. Это не внутридневной online alarm.
14. **Что с майской площадью?** Измеренный масштаб меняется; причина не подтверждена. Параметр исключен из main detectors, сырые значения и sensitivity сохранены.
15. **С какого дня изменился NK-7?** Месячные данные показывают снижение уже в мае; точную дату и физическую причину они не устанавливают.
16. **Используется ли будущее в event context?** Да, только в ретроспективном окне объяснения после события; в детектор и настройку порогов эти признаки не подаются.
17. **Что значит confirmed?** Человеческий статус review кандидата; это не официальная метка отказа и не учебная целевая переменная.
18. **Достаточен ли размер данных?** Источник реально меньше рекомендации; это открытый пункт для согласования, строки не дублировались.
19. **Почему без GPU?** Данные и методы укладываются в измеренные CPU-ресурсы. Утверждения об ускорении GPU отсутствуют.
20. **Как воспроизвести без сети?** Установить зависимости заранее, prepare sample из комплектного реального Parquet, enhance sample и Streamlit; есть offline HTML и SQL exports.
